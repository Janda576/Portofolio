# Portofolio Arjuna Dirgantara

Website portofolio satu halaman yang dibuat dengan HTML, CSS, dan JavaScript murni. Paket tidak memerlukan instalasi, framework, atau proses build.

## Publikasi ke GitHub Pages

1. Ekstrak file ZIP.
2. Unggah seluruh isinya ke bagian utama repository GitHub.
3. Pastikan `index.html` berada langsung di root repository.
4. Buka **Settings > Pages**.
5. Pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**.
7. Klik **Save** dan tunggu deployment selesai.

## Data yang perlu diganti

Buka `index.html`, lalu ganti:

- `arjuna.dirgantara@example.com` dengan alamat email yang ingin digunakan.
- `https://github.com/` dan teks “Tambahkan akun GitHub Anda” dengan profil GitHub yang benar.

Alamat contoh tidak menyebabkan error, tetapi belum mengarah ke kontak pribadi.
